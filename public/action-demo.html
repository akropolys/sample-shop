Try it through Kiku

In Shell → Agents → Actions, add these four actions from the definitions JSON. Enable Kiku access for all four and leave Require sign-in off.

On demo_checkout, set Before to demo_before, After success to demo_after, and On return to demo_on_return. Save the helper actions first, then set the links.

In the shop’s Kiku chat, say: “Start the free demo checkout.” Open the link Kiku gives you, complete or cancel, then switch back to that same chat tab.

After success records creation of the demo session. On return checks whether you completed or cancelled it. The normal Stripe checkout remains separate.
